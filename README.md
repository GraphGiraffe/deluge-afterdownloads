# AfterDownloads для Deluge

Нативный плагин Deluge 2.x GTK3: дождаться загрузок, показать минутный таймер и выполнить выбранное действие питания. Windows — основной проверяемый вариант. Linux с systemd/logind — **NOT TESTED** на реальном устройстве.

## Платформы

| Платформа | Реализация | Проверка |
| --- | --- | --- |
| Windows 10/11, Deluge 2.x GTK3 | Win32 API, отдельный поток Awake | Автотесты на Windows; работа подтверждена пользователем в Deluge 2.2.0 |
| Ubuntu и другие Linux с systemd/logind | systemd-inhibit, D-Bus logind через busctl | Автотесты в Ubuntu 26.04 WSL; GTK и реальные действия питания — **NOT TESTED** |
| Linux без systemd/logind | Не поддерживается | Действия отключены |
| macOS, FreeBSD | Не реализовано | Не поддерживается; действия отключены |

## Возможности

- Сон, гибернация или выключение — радиокнопки в настройках Deluge.
- Проверка доступности сна и гибернации при включении, открытии настроек, запуске ожидания и перед действием. Недоступные пункты отключены; причина показана отдельной строкой.
- Незавершённые торренты на паузе игнорируются; загрузки в очереди, проверка файлов и ошибки препятствуют действию.
- Запрет автоматического сна: в Windows отдельный поток с `ES_CONTINUOUS | ES_SYSTEM_REQUIRED` по подходу PowerToys Awake; в Linux — `systemd-inhibit`. Экран может выключаться.
- Отдельное окно с 60-секундным таймером и отменой. Закрытие окна также отменяет действие.
- Повторная проверка загрузок после таймера. Новая загрузка возвращает плагин к ожиданию.
- Dry-run проходит тот же сценарий без сна, гибернации или выключения.
- Настройки выбранного действия и dry-run сохраняются, но ожидание после перезапуска **не запускается автоматически**.
- Пароль и Web UI не нужны: используется текущее локальное соединение Deluge.
- Русский и английский интерфейс по языку Deluge; для остальных языков — английский. После изменения языка перезапустите Deluge. Технические названия Modern Standby, S0, S1–S3, dry-run и systemd/logind не переводятся.

## Установка

1. Скачайте `.egg` из релиза, соответствующий Python вашей сборки Deluge. Для официальной проверенной Windows-сборки Deluge 2.2.0 нужен `AfterDownloads-1.0.0-py3.9.egg`.
2. Откройте **Настройки → Плагины → Установить плагин**, выберите `.egg`, включите **AfterDownloads**. Если не появился — перезапустите Deluge.
3. В настройках откройте страницу **AfterDownloads**, выберите доступное действие и нажмите **Начать ожидание**. Первый запуск удобно проверить с галочкой **Только проверка**.

Deluge должен оставаться запущенным; сворачивание в трей допустимо. При отключении плагина, закрытии Deluge или потере соединения действие отменяется и запрет сна снимается. Окно настроек можно закрывать — мониторинг продолжается. Не включайте одновременно другое приложение автоматического выключения.

## Ограничения

Плагин управляет компьютером с открытым GTK-интерфейсом Deluge, а не удалённым сервером. Удалённые соединения блокируются. Без оконного интерфейса или через один Web UI автоматические действия не выполняются.

В Linux нужны systemd/logind, `busctl`, `systemd-inhibit` и обычный Python в `sys.executable`. Разрешение запрашивается через `CanSuspend`, `CanHibernate`, `CanPowerOff`. Разрешено только `yes`: ответы `no`, `na` или `challenge` отключают пункт. Повышение прав автоматически не запрашивается. Для гибернации Linux дополнительно нужны настроенные swap/resume и поддержка ядра. Inhibitor снимается перед действием. Frozen/AppImage-сборки с нестандартным `sys.executable` могут не поддержать helper — это также **NOT TESTED**.

Сон через используемый Windows API разрешён только при наличии S1–S3. На устройствах только с Modern Standby S0 кнопка отключена, поскольку этот вызов может переводить систему в гибернацию. Сам S0 в Windows при этом не выключается. Наличие S1–S3 не гарантирует исправность прошивки и драйверов; проверьте на своём устройстве. Гибернация проверяется через `IsPwrHibernateAllowed`.

Ручной сон, блокировка сеанса, закрытие крышки и защитные действия при критическом заряде не отменяются плагином. При пустом списке торрентов действие не запускается; если все торренты на паузе, минутный таймер запускается. Выключение не использует `/f`: программы с несохранёнными данными могут помешать завершению работы.

## Разработка и сборка

Только стандартная библиотека Python для сборки и тестов; зависимости Deluge, GTK3 и Twisted предоставляет сам Deluge.

```sh
python -m unittest discover -s tests -v
python build.py --python-version 3.9
```

Результат: `dist/AfterDownloads-1.0.0-py3.9.egg`. Это ZIP с исходным Python-кодом и метаданными Deluge, без EXE/DLL и сторонних зависимостей. Другие имена версии Python доступны в сборщике; загрузка непосредственно в Deluge проверена только для конфигурации, указанной в [TESTING.md](docs/TESTING.md).

Релиз содержит пакеты с тегами Python 3.9–3.14 и файл контрольных сумм `SHA256SUMS.txt`. Содержимое пакетов одинаковое; тег выбирается по Python, на котором работает Deluge.
