# Changelog

## 1.0.0

- Первый нативный GTK3-плагин для Deluge 2.x на Windows.
- Реализация Linux с systemd/logind: NOT TESTED на реальном устройстве.
- Три действия питания с проверкой доступности сна и гибернации.
- Запрет сна с выключающимся экраном, фильтрация паузы, 60-секундная отмена, повторная проверка и dry-run.
- Отмена при ошибках связи и отключении; ожидание не восстанавливается автоматически.
- Русский/английский интерфейс по настройке языка Deluge, английский для остальных языков; технические термины сохранены.
- Пояснение вверху настроек: запрет автоматического сна во время ожидания, выбранное действие после завершения активных загрузок и минутная отмена.
- Воспроизводимые source-only `.egg` для Python 3.9–3.14; проверки Windows/Ubuntu и artifact релиза для публикации от имени владельца.
