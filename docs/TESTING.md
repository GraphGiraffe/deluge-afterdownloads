# Проверки и ограничения

## Локально, Windows, 2026-09-24

- Python 3.13.13: `python -m unittest discover -s tests -v` — 30 тестов прошли.
- Проверены приоритет языка Deluge над системным, автоматический выбор через активный gettext, английский fallback, полнота каталога переводов и совпадение параметров форматирования. Визуальная проверка обоих языков в реальном GTK после последнего обновления — NOT TESTED.
- Проверены фильтрация торрентов, полный минутный отсчёт, обязательный свежий ответ перед действием, возврат к ожиданию при новой загрузке, отмена, потеря соединения, устаревшие callbacks и dry-run без вызова питания.
- Реально вызваны Windows API определения доступности и установки/снятия запрета сна. На проверенном устройстве S1–S3 недоступны, гибернация доступна.
- Deluge 2.2.0 Windows / встроенный Python 3.9: `.egg` установлен, core и GTK-компонент загружены. Диагностика после перезапуска подтверждает `loaded=true`, `armed=false` и доступность действий.
- Пользователь подтвердил работу плагина в Deluge после обновлений интерфейса. Это ручное подтверждение работоспособности; отдельные результаты для каждого действия питания и английского интерфейса не зафиксированы.
- Проверены совпадение версии в сборщике, core, CHANGELOG и release notes, а также синтаксис модулей для Python 3.9.
- Сборка повторяема побайтово между Windows и Ubuntu WSL, включая различающиеся окончания строк. В `.egg` нет EXE, DLL, паролей или пользовательской конфигурации.
- Автоматизированная проверка полного сценария использует заглушки GTK/Deluge. Реальные переходы питания каждого типа отдельно агентом не проверялись.

## Другие окружения

- Ubuntu 26.04 в WSL, Python 3.14.4: 29 тестов прошли, 1 тест Windows API пропущен. Mock-тесты проверяют ответы CanSuspend/CanHibernate/CanPowerOff и выбор методов D-Bus без интерактивной авторизации.
- Linux с systemd/logind: реальные GTK-интерфейс, inhibitor, сон, гибернация и выключение — **NOT TESTED**. WSL не заменяет проверку на физическом компьютере.
- Python 3.10–3.14 внутри реального Deluge: **NOT TESTED**. Тег версии в имени `.egg` не доказывает совместимость с конкретной сборкой Deluge.
- macOS, FreeBSD, Linux без systemd/logind: не реализовано, действия отключены.
- GitHub Actions настроены, но до загрузки репозитория не запускались.

## Ручная проверка перед публикацией

1. Установить `.egg`, включить плагин и при необходимости полностью перезапустить Deluge. Открыть страницу AfterDownloads в настройках.
2. Проверить, что недоступные действия неактивны и имеют объяснение. На другом компьютере доступность определяется заново.
3. Включить «Только проверка», выбрать доступное действие, начать ожидание. Проверить незавершённый торрент, торрент на паузе и завершённый торрент.
4. Проверить минутный отсчёт, кнопку отмены и закрытие окна отсчёта. Повторно запустить и дождаться сообщения об успешном dry-run; питание не должно измениться.
5. Во время отсчёта добавить/возобновить незавершённую загрузку: действие должно вернуться к ожиданию. При потере соединения или отключении плагина ожидание должно отмениться.
6. Убедиться, что экран гаснет, автоматический сон блокируется во время ожидания и запрет снимается после отмены.
7. Реальные действия проверять отдельно после сохранения работы. На Linux сначала подтвердить настройку гибернации самой ОС. Записать ОС, версию Deluge/Python и фактические результаты, затем обновить этот документ.
