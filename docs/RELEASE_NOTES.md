# AfterDownloads 1.0.0

Плагин Deluge GTK3 для Windows и Linux с systemd/logind: сон, гибернация или выключение после завершения загрузок. Торренты на паузе игнорируются, экран может гаснуть, перед действием появляется минутный таймер с отменой.

Windows: работа плагина подтверждена пользователем в Deluge 2.2.0. Linux: GTK и реальные действия питания — **NOT TESTED**; автотесты прошли в Ubuntu 26.04 WSL. macOS и FreeBSD не реализованы и не заявляются как поддерживаемые.

Установите `.egg`, соответствующий версии Python в Deluge (сборки для Python 3.9–3.14). Для проверенной Windows-сборки Deluge 2.2.0 используется `py3.9`. Рядом приложен SHA256SUMS.txt.

Русский и английский интерфейс выбирается по языку Deluge, остальные языки используют английский. Технические названия Modern Standby, S0 и dry-run не переводятся.

Недоступные сон и гибернация отключаются автоматически. На устройствах только с Modern Standby S0 кнопка сна отключена из-за особенностей используемого API. Удалённые подключения и headless/Web UI без GTK не поддерживают выполнение действий. Пароль Web UI не требуется.

Включение плагина не запускает ожидание: откройте его страницу в настройках и нажмите «Начать ожидание». Для первой проверки используйте dry-run.
